LUNEX — чаты в реальном времени (Firestore)
===========================================

В архиве сохранены Firebase Authentication, восстановление пароля и интерфейс LUNEX.
Добавлена возможность искать пользователей по email, создавать личные переписки и обмениваться сообщениями через Cloud Firestore.

ВАЖНО: Firebase Authentication не включает Firestore автоматически. Перед запуском:

1. Открой Firebase Console → проект lunex-100db → Build → Firestore Database.
2. Нажми Create database и создай базу данных.
3. Открой Firestore → Rules и опубликуй правила из файла firestore.rules.
4. В Authentication → Settings → Authorized domains добавь домен, на котором запускаешь приложение.
5. Запускай через хостинг/локальный сервер с HTTPS (не открывай ES-модуль как file://).

Как пользоваться:
- Зарегистрируйся и подтверди email.
- Другой пользователь также должен зарегистрироваться и подтвердить email.
- В поле «Найти человека по email» введи точный email второго пользователя.
- Выбери переписку и отправляй сообщения. Обновления приходят в реальном времени.

Пользователи могут находить друг друга только по точному email. Пароли не сохраняются в Firestore.
Правила в firestore.rules ограничивают чтение/запись участниками переписки.

Пока реализованы личные текстовые сообщения. Группы, вложения, звонки, push-уведомления и блокировка пользователей ещё не реализованы.
